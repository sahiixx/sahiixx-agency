# Advanced Prompts

## 1. Build the System, Not the One-Off
Use this when you catch yourself doing the same task more than twice.

I just spent time on [describe the task].

Before I move on, help me decide:
1. Is this a one-time task, or will I do it again in the next 30 days?
2. If repeating, walk me through what a process file would look like.
3. Draft a first version of that process file.
4. Tell me what I'd save in hours per week if we shipped this today.

Don't write the full thing yet. Show me a 5-line draft and ask if it's worth building out.

## 2. The Subscriber Reply Batch
Use this every Friday. Paste in every reply that came in that week.

Below are all the replies I received this week. Treat them as one batch.
[Paste all replies here, separated by ===]

Your job:
1. Categorize each reply:
  - Quick thank-you (no reply needed)
  - Easy question (draft a short reply)
  - Real feedback (summarize for me, no reply needed)
  - Needs my personal voice (just flag it, don't draft)
  - Sponsor or business opportunity (flag urgently)
2. For 'easy question' replies, draft a response in my voice. Keep each one under 60 words.
3. For 'real feedback' replies, give me a 3-bullet summary of patterns.
4. For 'needs my personal voice', paste the original and add: "Why this needs you."

Show me the batch in a single clean table.

## 3. The Big Decision Call
Use this when you're stuck on a real call. Should I launch this? Take this sponsor? Quit this project?

I'm stuck on a decision. Here's the situation: [Describe the decision in 3 to 5 sentences.]

Before you answer, read who-i-am.md, what-i-do.md, and operating-context.md.

Then:
1. Tell me which file is most relevant and quote the exact line that applies.
2. Lay out the decision as 'if A, then...' / 'if B, then...' for 90 days out.
3. Flag any way this contradicts what I said I'd do this quarter.
4. Recommend one path. 3 sentences max. End with: "But this is your call, here's what you should think about overnight."

Don't try to be agreeable. I need the version of you that pushes back.
