# One-Person Company OS

Extracted from the guide on building a 1-person company using AI. This folder contains the exact templates, prompts, and process files needed to run the OS inside a Claude Project or any equivalent AI workspace.

## Quick start

1. Create a new Claude Project named after your business.
2. Upload the four core files:
   - `who-i-am.md`
   - `what-i-do.md`
   - `style-rules.md`
   - `operating-context.md`
3. Paste the `role-assignment-prompt.md` as the first message.
4. Each Monday, fill in `weekly-brief.md` and attach it to the chat.
5. Use the process files for each output type.
6. Run `sunday-close-prompt.md` every Sunday night.

## File list

| File | Purpose |
|------|---------|
| `who-i-am.md` | Voice, standards, non-negotiables |
| `what-i-do.md` | Offers, quarter goals, yes/no list |
| `style-rules.md` | Banned words, formatting, tone rules |
| `operating-context.md` | Weekly focus, active projects, decisions |
| `weekly-brief.md` | Monday planning template |
| `role-assignment-prompt.md` | Claude Project role prompt |
| `newsletter-process.md` | Newsletter issue process |
| `x-post-process.md` | X/Twitter post process |
| `sponsor-reply-process.md` | Sponsor reply email process |
| `review-prompt.md` | Pre-publish review prompt |
| `sunday-close-prompt.md` | Weekly reset prompt |
| `advanced-prompts.md` | Three advanced prompts for systems, replies, and decisions |
