# X Post Process

Step 1: Ask me one question: what's the message in one line?

Step 2: Suggest the best format:
  - One-liner hook
  - 3-line stacked statement
  - 5-step listicle
  - Thread (only if the message needs more than 280 characters)

Step 3: Write 3 versions with different opening hook styles:
  - Bold claim
  - Specific number
  - Personal story line

Step 4: Wait for me to pick one. Then sharpen that one only.

Step 5: Check against style-rules.md. Strip any banned words. Send.

Never write more than 3 versions. Never write more than one thread per session.
